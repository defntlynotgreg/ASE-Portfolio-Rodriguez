## Personal Learning Goals
- Understand how to design, build, and test software systems powered by autonomous AI agents.
- Apply Agile methods like Scrum and use Git version control effectively to manage code and track changes.
- Learn how to identify AI risks, protect user privacy, and apply security practices when deploying autonomous systems.
- Practice responsible AI development by keeping human oversight and ethical standards part of every project.

## Reflection from Part A
Completing the Concept Analysis helped me clearly see the difference between traditional rule-based software and autonomous AI agents. Unlike regular programs that always follow fixed instructions, AI agents sense their environment, adapt, and make decisions on their own. Because their behavior can be unpredictable, traditional step-by-step development is not enough. Using Agile methods like Scrum and tracking work with Git gives developers a safe way to test, inspect, and improve these systems in small steps. Most importantly, I learned that building smart AI is not just a technical task. Following guidelines like the NIST AI Risk Management Framework and keeping human oversight in place are necessary to prevent errors, reduce bias, protect security, and keep users safe.
